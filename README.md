# Employee Performance Analysis Dashboard

## Project Overview

The Employee Performance Analysis Dashboard is a business analytics project developed during my Data Analyst Internship at Akshara Enterprises.

The project focuses on analyzing employee performance, monitoring assigned targets, evaluating sales-related activities, and providing management with insights into employee productivity and target achievement.

I collected and audited employee performance data, organized the records using Excel and Power Query, and developed an interactive Power BI dashboard to support performance monitoring and management reporting.

## Objectives

- Monitor employee targets against actual performance.
- Analyze target achievement and employee productivity.
- Track positive responses, sales-related conversions, and COS performance.
- Evaluate employee work progress and performance status.
- Identify missed targets and areas requiring improvement.
- Support management reporting and performance-based variable pay calculations.

## Tools and Technologies

- **Microsoft Excel:** Data collection, organization, validation, and preparation.
- **Power Query:** Data cleaning, transformation, and consolidation.
- **Power BI:** Interactive dashboard development and data visualization.
- **DAX:** KPI calculations, performance measures, and analytical metrics.

## Project Workflow

1. **Data Collection:** Collected employee performance records, target details, and daily work reports from internal company sources.
2. **Data Auditing:** Reviewed employee records and verified reported activities and performance information.
3. **Data Preparation:** Cleaned, categorized, and consolidated data using Excel and Power Query.
4. **KPI Development:** Created measures to evaluate targets, actual performance, achievement percentages, and other relevant performance indicators.
5. **Dashboard Development:** Built an interactive Power BI dashboard to visualize employee performance and target progress.
6. **Performance Analysis:** Used the dashboard to identify performance gaps and provide insights for management review.

## Key Performance Indicators

- Target vs. Actual Performance
- Target Achievement Percentage
- Positive Responses and POS Percentage
- COS Performance and COS Percentage
- Employee Work Progress
- Daily and Weekly Performance Trends
- Performance Status and Missed Targets

*The exact KPIs displayed depend on the available data and the measures implemented in the Power BI report.*

## Business Impact

The dashboard provides a consolidated view of employee performance and helps management:

- Monitor employee productivity and target completion.
- Identify employees who meet or miss their assigned targets.
- Review performance trends and areas requiring improvement.
- Support performance evaluation and variable pay calculations.
