# Data Dictionary

| Column | Description |
|---|---|
| Date | Date of the employee's performance record |
| Employee | Employee name or anonymized identifier |
| Call_Target | Assigned call target |
| Answered calls | Number of answered calls |
| Positive | Number of positive responses |
| COS | COS performance measure |
| Visits | Number of visits recorded |
| Work_Progress | Status of assigned work |
| Target_Achievement_% | Actual performance relative to the applicable target |
| Performance_Category | Performance classification based on your implemented rules |
